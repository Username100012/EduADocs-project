## **Plano de Aula: Busca Linear em Vetores**

### **1. Dados do plano de aula:**
- **Tema:** Busca linear em vetores
- **Nível:** Ensino Médio / Início do Ensino Superior
- **Duração:** 2 aulas (45 minutos cada)
- **Objetivos:**
  - Compreender o conceito de busca linear em vetores.
  - Identificar as diferenças entre busca linear e busca binária.
  - Implementar algoritmos de busca linear em vetores.
  - Resolver problemas práticos com busca linear.

---

### **2. Conteúdo Programático:**

#### **Aula 1: Introdução à Busca Linear**

**Objetivos da aula:**
- Explicar o conceito de vetor.
- Introduzir o conceito de busca linear.
- Discutir a complexidade de tempo da busca linear.
- Mostrar exemplos práticos de busca linear.

**Conteúdo:**

- **Vetor (array):** Estrutura de dados que armazena uma sequência de elementos.
- **Busca linear:** Procedimento para localizar um elemento em um vetor, verificando cada elemento um a um.
- **Complexidade de tempo:** O(n), onde n é o número de elementos no vetor.
- **Exemplo prático:** Buscar um número em uma lista de números.

**Atividade:**
- Exemplo de código em Python para busca linear.
- Perguntas de reflexão:
  - Por que a busca linear é útil?
  - Em quais situações a busca linear é a melhor opção?

---

#### **Aula 2: Aplicação e Comparação com Busca Binária**

**Objetivos da aula:**
- Comparar a busca linear com a busca binária.
- Implementar um algoritmo de busca linear em Python.
- Resolver problemas práticos com busca linear.
- Refletir sobre a eficiência dos algoritmos.

**Conteúdo:**

- **Comparação entre busca linear e busca binária:**
  - Busca linear: simples, mas lenta.
  - Busca binária: mais eficiente, mas exige que o vetor esteja ordenado.
- **Exemplo prático de busca linear em Python.**
- **Exercícios de aplicação:**
  - Buscar um elemento em um vetor.
  - Verificar se um elemento existe no vetor.
  - Criar um programa que lê um vetor e busca um valor inserido pelo usuário.

**Atividade:**
- Exercício prático: Implementar um programa de busca linear.
- Perguntas de reflexão:
  - Qual é a vantagem de usar a busca linear em relação à busca binária?
  - Em que cenários a busca linear é mais adequada?
