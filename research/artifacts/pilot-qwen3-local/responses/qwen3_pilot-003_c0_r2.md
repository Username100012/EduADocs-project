---

## **Plano de Aula: Requisitos Funcionais e Não Funcionais de um Sistema de Biblioteca**

### **Duração:** 2 aulas (90 minutos cada)

### **Objetivos de Aprendizagem:**
1. Entender o conceito de **requisitos funcionais** e **não funcionais** em sistemas de informação.
2. Identificar e classificar os requisitos de um sistema de biblioteca.
3. Aplicar os conceitos em um exemplo prático de sistema de biblioteca.
4. Desenvolver habilidades de análise e planejamento de sistemas.

---

### **Conteúdo Programático:**

#### **1. Introdução (10 minutos)**
- Definição de sistema de biblioteca.
- Importância de um sistema de gestão de biblioteca.
- Requisitos como base para o projeto de sistemas.

#### **2. Requisitos Funcionais (30 minutos)**
- **Definição:** Funcionalidades que o sistema deve realizar.
- Exemplos de requisitos funcionais em um sistema de biblioteca:
  - Cadastro de livros (título, autor, editora, etc.)
  - Consulta de livros
  - Empréstimo e devolução de livros
  - Gerenciamento de membros (usuários)
  - Relatórios de uso e estoque
  - Busca avançada de livros
- Atividade: Identificar requisitos funcionais de um sistema de biblioteca.

#### **3. Requisitos Não Funcionais (30 minutos)**
- **Definição:** Restrições e características do sistema que não são diretamente funcionais, mas influenciam no funcionamento e uso do sistema.
- Exemplos de requisitos não funcionais em um sistema de biblioteca:
  - **Performance:** Tempo de resposta para buscas
  - **Segurança:** Proteção de dados de usuários
  - **Usabilidade:** Interface amigável
  - **Disponibilidade:** Funcionamento 24/7
  - **Escalabilidade:** Capacidade de crescer com o número de usuários
  - **Confiabilidade:** Menos erros e falhas
  - **Compatibilidade:** Funcionamento em diferentes dispositivos e navegadores
- Atividade: Classificar requisitos não funcionais de um sistema de biblioteca.

#### **4. Aplicação Prática (20 minutos)**
- Exemplo prático: Desenhar um **modelo de requisitos** para um sistema de biblioteca.
- Dividir a turma em grupos e pedir que cada grupo:
  - Liste os requisitos funcionais e não funcionais de um sistema de biblioteca.
  - Representem os requisitos em um diagrama ou tabela.

#### **5. Conclusão e Refletir (10 minutos)**
- Revisão dos conceitos.
- Perguntas de reflexão:
  - Por que os requisitos não funcionais são importantes?
  - Como os requisitos funcionais e não funcionais se complementam?
  - Qual é a importância de planejar os requisitos antes de desenvolver um sistema?
