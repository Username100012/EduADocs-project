057: **9. Conteúdo Teórico (Introdução):**
058: 
059: - **Ordenação por bolha:** Algoritmo de ordenação simples, em que os elementos são comparados e trocados se estiverem em ordem incorreta.
060: - **Passagem de trocas adjacentes:** Durante cada passagem, os elementos são comparados dois a dois, e se estiverem em ordem inversa, são trocados.
061: - **Maior valor no final:** Após uma passagem completa, o maior valor estará na última posição, pois ele foi "empurrado" para a direita durante as trocas.
062: 
063: ---
064: 
065: **10. Atividade Prática (em grupos de 3–4 alunos):**
066: 
067: **Passo 1:**  
068: Distribuir a cada grupo uma sequência de números (ex: [5, 3, 8, 1, 2]).
069: 
070: **Passo 2:**  
071: Simular uma passagem de trocas adjacentes, comparando elementos dois a dois e trocando se necessário.
072: 
073: **Passo 3:**  
074: Registrar o vetor após cada comparação (ex: [5, 3, 8, 1, 2] → [3, 5, 8, 1, 2] → [3, 5, 8, 1, 2] → ...).
075: 
076: **Passo 4:**  
077: Identificar o maior valor e verificar onde ele termina após a passagem.
078: 
079: ---
080: 
081: **11. Discussão e Análise:**
082: 
083: - **Perguntas para estimular a reflexão:**
084:   - Por que o maior valor acaba na última posição?
085:   - Qual é o papel da passagem de trocas adjacentes?
086:   - Como a passagem completa contribui para a ordenação?
087:   - Qual é a vantagem de repetir a passagem até que não haja mais trocas?
088: 
089: - **Resposta esperada:**  
090:   - O maior valor é "empurrado" para a direita em cada comparação, terminando na última posição após a passagem.
