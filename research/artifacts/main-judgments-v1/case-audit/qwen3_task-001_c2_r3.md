001: **Plano de Aula: Identificação do Maior Elemento de um Vetor**
002: 
003: ---
004: 
005: **Tópico:** Maior elemento de um vetor não vazio  
006: **Nível educacional:** Graduação em Ciência da Computação – Formação introdutória  
007: **Duração:** 50 minutos  
008: **Metodologia:** Resolução colaborativa de problemas  
009: **Materiais e recursos:** Quadro, folha com vetores de inteiros para testes de mesa  
010: **Estratégia de avaliação:** Entrega de pseudocódigo e dois testes de mesa (um com valores negativos, outro com máximo repetido)
011: 
012: ---
013: 
014: ### **Objetivos de Aprendizagem:**
015: - Compreender a estrutura de algoritmos para identificação do maior elemento em um vetor.
016: - Implementar em pseudocódigo uma solução para encontrar o maior elemento de um vetor de inteiros não vazio.
017: - Testar algoritmos com diferentes casos de entrada, incluindo valores negativos e elementos repetidos.
018: - Desenvolver habilidades de resolução de problemas colaborativa e de pensamento crítico.
019: 
020: ---
021: 
022: ### **Conteúdo Programático:**
023: - Conceito de vetor
024: - Estrutura de loop para percorrer elementos de um vetor
025: - Comparação de valores
026: - Variável de controle para armazenar o maior valor encontrado
027: - Casos de teste: valores negativos, valores positivos, valores repetidos
028: 
029: ---
030: 
031: ### **Etapas do Plano de Aula**
032: 
033: #### **1. Introdução (5 minutos)**
034: - Apresentar o conceito de vetor e o objetivo da aula.
035: - Discutir a importância de identificar o maior elemento em um vetor, com exemplos práticos.
036: - Explicar a estrutura do algoritmo que será desenvolvido.
037: 
038: #### **2. Explicação Teórica (10 minutos)**
039: - Explicar passo a passo como funciona o algoritmo para encontrar o maior elemento de um vetor.
040: - Mostrar a estrutura de pseudocódigo:
041:   ```
042:   Iniciar
043:   Definir vetor com elementos
044:   Definir maior = primeiro elemento do vetor
045:   Para cada elemento no vetor:
046:       Se elemento > maior:
047:           maior = elemento
048:   Imprimir maior
049:   Fim
050:   ```
051: - Discutir a necessidade de inicializar a variável `maior` com o primeiro elemento do vetor.
052: - Apresentar os casos de teste que serão utilizados: valores negativos, valores positivos e valores repetidos.
053: 
054: #### **3. Resolução Colaborativa (20 minutos)**
055: - Dividir a turma em grupos de 3 a 4 alunos.
056: - Cada grupo recebe um vetor de inteiros para testar.
057: - Cada grupo deve:
058:   - Implementar o pseudocódigo para identificar o maior elemento.
059:   - Fazer os testes de mesa com os vetores fornecidos.
060:   - Registrar os resultados e a saída esperada.
061: - Os grupos apresentam seus resultados para a turma, discutindo os passos e as possíveis falhas.
062: 
063: #### **4. Discussão e Avaliação (10 minutos)**
064: - Cada grupo apresenta o pseudocódigo e os testes de mesa.
065: - Professora/coordenadora orienta os alunos a analisar os resultados.
066: - Revisar os casos de teste, destacando os pontos importantes:
067:   - Valores negativos: como o algoritmo lida com números negativos.
068:   - Valores repetidos: como o algoritmo identifica o maior valor mesmo que ele apareça mais de uma vez.
069: - Avaliar os pseudocódigos e testes de mesa com base no critério estabelecido.
070: - Fazer uma análise geral dos resultados e corrigir eventuais erros.
071: 
072: #### **5. Encerramento (5 minutos)**
073: - Resumir os conceitos principais da aula.
074: - Destacar a importância da resolução de problemas colaborativa.
075: - Entregar os pseudocódigos e os testes de mesa como avaliação.
076: - Perguntas finais para reforçar o conteúdo.
077: 
078: ---
079: 
080: ### **Avaliação:**
081: - **Pseudocódigo:** Correto e claramente estruturado, com identificação do maior elemento.
082: - **Testes de Mesa:**
083:   - **Teste 1:** Vetor com valores negativos (ex.: [-5, -3, -10, -2])
084:   - **Teste 2:** Vetor com valores repetidos (ex.: [10, 10, 5, 10])
085: - **Nota:** 10 pontos para cada parte.
086: 
087: ---
088: 
089: ### **Recursos Necessários:**
090: - Quadro de whiteboard para anotações
091: - Folhas com vetores de inteiros para testes de mesa
092: - Canetas, lápis, papel para anotações
093: - Páginas de referência sobre estruturas de dados e algoritmos
094: 
095: ---
096: 
097: ### **Observações:**
098: - Os alunos devem ter conhecimento básico de estruturas de repetição e comparação.
099: - O professor deve estar atento ao desenvolvimento dos grupos, fornecendo ajuda quando necessário.
100: - O objetivo é promover a resolução colaborativa e a compreensão do funcionamento de algoritmos.
